# Перетягивание каната: Битва знаний

Учебная веб-игра React + TypeScript + Vite. Игровые правила отделены от интерфейса.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес из терминала. В PowerShell используйте `npm.cmd`, если выполнение `npm.ps1` запрещено. В других оболочках можно использовать `npm`.

```powershell
npm.cmd test
npm.cmd run test:watch
npm.cmd run build
npm.cmd run preview
npm.cmd run lint
```

Чтобы явно выбрать порт:

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

## Как пройти матч

1. Прочитайте правила на стартовом экране и нажмите «Начать игру».
2. Дождитесь отсчёта 3–2–1.
3. Выберите ставку и ответ, нажмите «Подтвердить». Либо нажмите «Отдохнуть» без выбора ответа.
4. После раунда прочитайте правильный ответ и результаты обоих участников. Таймер на этом экране остановлен.
5. Нажмите «Следующий вопрос». При достижении границы или после 12-го вопроса появится кнопка «Показать результат».
6. На экране результата нажмите «Реванш»: энергия, положение каната, вопросы, выбор и таймеры сбросятся. Снова начнётся отсчёт.

В проекте 12 тестовых вопросов. Бот случайно выбирает вариант и доступную ставку, при энергии 0–1 отдыхает. Он не получает правильный ответ или выбор игрока. Набор вопросов в каждом матче одинаковый; состояние между перезагрузками страницы не сохраняется.

## Структура

```text
src/
  game/
    types.ts             # вопросы, действия и состояние
    engine.ts            # чистые функции расчёта и константы правил
    bot.ts               # выбор действия бота
    session.ts           # этапы матча и защита от запоздалых событий
    engine.test.ts       # проверки правил
    session.test.ts      # проверки переходов между этапами
  components/
    Countdown.tsx        # начальный отсчёт
    QuestionRound.tsx    # выбор, подтверждение и таймер вопроса
    Rope.tsx             # канат с центром и границами
    RoundReview.tsx      # правильный ответ и результаты раунда
  data/questions.ts      # тестовые вопросы
  App.tsx                # связывает этапы матча с интерфейсом
  App.test.tsx           # проверки полного матча и таймеров React
  main.tsx
  index.css
vite.config.ts           # Vite и настройки Vitest
```

## Где менять правила и время

В `src/game/engine.ts`:

- `ROUND_DURATION_MS = 12_000` — длительность вопроса в миллисекундах. Например, `20_000` даст 20 секунд. Текст правил и начальное значение таймера берутся из этой константы.
- `MAX_ENERGY = 5` — начальная и максимальная энергия.
- `WIN_POSITION = 10` — границы победы; границы каната тоже берутся отсюда.
- `QUESTION_LIMIT = 12` — максимум вопросов. В банке должно быть не меньше этого количества.
- `resolveAction` — сила действия, списание ставки и восстановление энергии.
- `calculateRound` — сдвиг каната и расчёт нового состояния.
- `checkWinner` — условия победы и ничьей.
- `createGame` — начальное состояние, которое используется и при реванше.

Начальный отсчёт задаёт `COUNTDOWN_SECONDS = 3` в `src/components/Countdown.tsx`.
Вопросы меняйте в `src/data/questions.ts`: ровно 4 варианта, `correctAnswer` — индекс от 0 до 3.
Стратегия бота находится в `src/game/bot.ts`.

При изменении механики ставок обновляйте также тип `Bet` в `types.ts`, варианты в `QuestionRound.tsx`, стратегию бота и текст правил в `App.tsx`. После изменения правил обновите ожидаемые значения тестов.

## Важные решения

Движок не читает часы и не генерирует случайные числа: одинаковые аргументы дают одинаковый результат, исходное состояние не меняется. Недопустимые ставки отклоняются. После завершения действия не меняют результат. Пересечение границы тоже считается победой; фактическая позиция может быть +11, а визуальная отметка остаётся на границе.

Этапы матча: `start → countdown → question → review → question/result`. Результат последнего раунда показывается перед итоговым экраном, поэтому правильный ответ можно увидеть и после победы.

`sessionReducer` принимает ответы только на этапе вопроса и проверяет номер раунда и матча. Это отсекает двойные и устаревшие события, в том числе от предыдущего матча. `QuestionRound` дополнительно блокирует повторную отправку синхронно через ref.

Таймеры создаются в эффектах и очищаются при отправке действия и размонтировании компонентов. Новый вопрос и реванш получают новые компоненты с пустым выбором. При клике также проверяется срок: если 12 секунд уже прошли, отправляется `timeout`, даже если браузер ещё не вызвал интервал. Тайм-аут восстанавливает 1 энергию, отдых — 3. Фоновые вкладки могут задерживать выполнение таймеров браузером, но поздний ответ не принимается.

## Проверки

41 автоматический тест: правила движка, защита этапов матча, отсчёт, подтверждение, показ правильного ответа, тайм-аут, полный матч из 12 вопросов, результат, реванш и очистка таймеров, включая React StrictMode.

React-тесты работают в jsdom с управляемыми часами. Это не визуальная проверка в настоящем браузере. В текущей сессии подключённый браузер недоступен; dev-сервер проверен HTTP-запросами.

Документация: [Vite](https://vite.dev/guide/), [Vitest](https://vitest.dev/guide/).
