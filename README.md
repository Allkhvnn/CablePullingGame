# Перетягивание каната: Битва знаний

Учебная веб-игра на React + TypeScript + Vite. Интерфейс намеренно простой; игровые правила не зависят от React.

## Запуск

В терминале из папки проекта:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который напечатает Vite. Нажмите «Начать игру», чтобы запустить первый таймер.
В Windows PowerShell используйте `npm.cmd`, если выполнение `npm.ps1` запрещено. В других оболочках подойдёт `npm`.

```powershell
npm.cmd test              # однократный запуск тестов
npm.cmd run test:watch    # тесты при изменении файлов
npm.cmd run build        # проверка TypeScript и сборка в dist/
npm.cmd run preview      # просмотр собранной игры
npm.cmd run lint         # проверка кода
```

```text

```

## Как устроена логика

- `createGame(questions)` создаёт полностью новую партию: по 5 энергии, канат 0, счётчик 0, без победителя и прошлого раунда. Для реванша вызывается та же функция. Нужно минимум 12 вопросов; используются первые 12.
- `resolveAction(energy, action, question)` рассчитывает силу и остаток энергии одного участника. Правильный ответ: +ставка, неправильный: −ставка; ставка списывается в обоих случаях, затем восстанавливается 1 энергия. Отдых даёт 0 силы и +3 энергии. Тайм-аут даёт 0 силы и только +1 энергии. Энергия не превышает 5.
- `calculateRound(state, playerAction, botAction)` рассчитывает оба действия на одном вопросе. Сдвиг равен силе игрока минус сила бота. Функция возвращает новое состояние, не меняя исходное. Недостаточная энергия или недопустимая ставка вызывают ошибку до изменения состояния.
- `checkWinner(position, roundsPlayed)` проверяет границы +10/−10, затем результат после 12 вопросов. Пересечение границы тоже считается победой; позиция сохраняет фактическое значение, например +11. При нуле после 12 вопросов — ничья.
- После завершения `calculateRound` возвращает прежнее состояние без обработки действий.

`Action` — объединение трёх вариантов: `answer`, `rest`, `timeout`. Так пропуск по времени нельзя случайно принять за отдых. Вопрос содержит ровно четыре варианта; индексы ответов — от 0 до 3, ставки — от 1 до 3. Включён строгий режим TypeScript.

Движок не читает часы и не генерирует случайные числа, поэтому одинаковый ввод всегда даёт одинаковый результат. Интерфейс отправляет `timeout` через 12 секунд и дополнительно проверяет срок при подтверждении ответа или отдыха. Выбор варианта без подтверждения не является ответом. Таймер обновляется раз в 100 мс; обработка в фоновой вкладке может задерживаться браузером, но просроченный ответ не принимается.

Бот пока выбирает случайный ответ (шанс правильного — 25%) и случайную доступную ставку. При энергии 0–1 отдыхает. Он не получает правильный ответ или выбор игрока. Случайные числа передаются в `chooseBotAction` снаружи, что позволяет тестировать его поведение. Следующий вопрос начинается сразу после расчёта раунда.

«Новая игра» и «Реванш» сбрасывают также выбор ответа, ставку и таймер интерфейса. Сохранения между перезагрузками страницы пока нет.

## Проверки

31 автоматический тест: верные и неверные ответы со всеми ставками, отдых, предел энергии, тайм-аут, нехватка энергии, движение каната, обе границы и их пересечение, исход после 12 вопросов, ничья, неизменность завершённой партии, реванш и поведение бота.

Выполнены успешно: `npm.cmd test`, `npm.cmd run build`, `npm.cmd run lint`.
Тесты проверяют движок; автоматические браузерные тесты интерфейса пока не добавлены.

Документация инструментов: [Vite](https://vite.dev/guide/), [Vitest](https://vitest.dev/guide/).
